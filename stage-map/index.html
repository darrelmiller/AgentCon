A2A v1 / Protocol architecture

One protocol. Three layers.

01 / SHARED VOCABULARY

Data model

Agent Cards, messages, parts, tasks, artifacts.
The objects agents exchange.

Extend the data

Add metadata and structured payloads.
Define schemas and profiles, not new core fields.

02 / SHARED BEHAVIOR

Operations

Send a message. Get or cancel a task. Subscribe to updates.
What agents can do with those objects.

Extend the behavior

Define new methods or interaction flows.
Layer workflow rules onto core operations.

03 / WIRE MAPPING

Protocol bindings

Map the same operations and data onto a concrete protocol.

JSON-RPC HTTP+JSON gRPC
Add a custom binding

Define a new mapping of A2A to a protocol.
Preserve the data model and operation semantics.

SLIMRPC / experimental

Extend each layer. Keep the core interoperable.
